# Databases

This project covers relational and non-relational databases as used in machine learning data pipelines.

## Topics

- MySQL: creating databases and tables, queries, indexes, stored procedures, triggers, views
- MongoDB: documents, collections, queries, aggregation, PyMongo

## Requirements

- Ubuntu 20.04 LTS
- MySQL 8.0
- MongoDB 4.4
- Python 3.9, PyMongo 4.6.2

## Tasks

Each task is in its own file, numbered in order. SQL files end in `.sql`, MongoDB scripts end in `.js`, Python scripts end in `.py`.

# Linear Algebra

First math project of the curriculum — getting comfortable with vectors
and matrices, first using plain Python lists and then numpy. If you've
ever wondered why everyone raves about numpy, doing the same operations
both ways in this project makes it painfully obvious.

The task names are... creative (they came with the curriculum, don't
blame me), but each one covers a real concept.

## Tasks

| File | What it does |
|------|--------------|
| `0-slice_me_up.py` | Basic list slicing — grabbing the first two, last five, etc. |
| `1-trim_me_down.py` | Slicing a 2D matrix to keep only certain columns |
| `2-size_me_please.py` | Figures out the shape of a nested-list matrix |
| `3-flip_me_over.py` | Transposes a 2D matrix by hand |
| `4-line_up.py` | Adds two arrays element by element |
| `5-across_the_planes.py` | Adds two 2D matrices (returns None if shapes don't match) |
| `6-howdy_partner.py` | Concatenates two arrays |
| `7-gettin_cozy.py` | Concatenates two matrices along a given axis |
| `8-ridin_bareback.py` | Matrix multiplication with pure Python — no numpy allowed |
| `9-let_the_butcher_slice_it.py` | Slicing a numpy array every which way |
| `10-ill_use_my_scale.py` | Gets the shape of a numpy array (the easy way) |
| `11-the_western_exchange.py` | Transposes a numpy array |
| `12-bracin_the_elements.py` | Element-wise add, subtract, multiply and divide with numpy |
| `13-cats_got_your_tongue.py` | `np.concatenate` along a chosen axis |
| `14-saddle_up.py` | Matrix multiplication, but now numpy does the heavy lifting |
| `100-slice_like_a_ninja.py` | Slices an array along specific axes from a dict of slices |
| `101-the_whole_barn.py` | Adds two matrices of any depth/dimension |

## Notes

- Python 3, pycodestyle-compliant
- The pure-Python tasks (0–8) don't import anything — that's the point

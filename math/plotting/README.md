# Plotting

Data visualization exercises using `numpy` and `matplotlib`.

## Requirements

- Ubuntu 20.04 LTS, `python3` (version 3.9)
- `numpy` (version 1.25.2), `matplotlib` (version 3.8.3)
- `pycodestyle` (version 2.11.1)
- Every file starts with `#!/usr/bin/env python3`, is executable, and ends
  with a new line
- All modules, classes and functions are documented

## Files

| File | Function | Description |
|------|----------|-------------|
| `0-line.py` | `line()` | Solid red line graph of y = x^3 |
| `1-scatter.py` | `scatter()` | Magenta scatter plot of height vs weight |
| `2-change_scale.py` | `change_scale()` | C-14 decay with a logarithmic y-axis |
| `3-two.py` | `two()` | Decay curves of C-14 and Ra-226 |
| `4-frequency.py` | `frequency()` | Histogram of student grades |
| `5-all_in_one.py` | `all_in_one()` | The five graphs in one 3x2 figure |
| `6-bars.py` | `bars()` | Stacked bar graph of fruit per person |
